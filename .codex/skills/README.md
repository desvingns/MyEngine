# Codex Skills

Repo-local skill shims may live here. Prefer thin adapters that reference canonical docs.

Registered MyEngine shims:

- `codex-plugins/me-dev/skills/me-dev/SKILL.md` -> `docs/agentic/PIPELINE.md`
- `codex-plugins/me-spec/skills/me-spec/SKILL.md` -> `docs/GAME_SPEC_PIPELINE.md`

The me-spec adapter also supports `--reference-game`, backed by
`scripts/me-reference-evidence.ps1`.
