# Tasks

This directory stores persistent task notes that should survive across sessions.

Use it for:

- in-progress phase notes;
- blockers that need user or human decision;
- follow-up work that should not be lost;
- ownership notes when multiple agents collaborate.

Suggested file format:

```markdown
# task-id-short-name

Status: Planned / In progress / Blocked / Done
Owner: Human / Codex / Claude
Created: YYYY-MM-DD

## Goal

## Context

## Next

## Blockers
```

Do not use this directory as a replacement for `STATE.md` or `Plane/README.md`.
