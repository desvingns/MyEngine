# Retro

This directory stores retrospectives and evidence-based improvement notes.

Future self-improvement loop:

1. Observe runs and failures.
2. Aggregate recurring issues.
3. Reflect in a short finding/evidence/proposal format.
4. Ask for human approval.
5. Apply approved changes.
6. Log changes in `.ai/changes/agent-skill-log.md`.

Do not allow self-improvement to mutate agent instructions, skills, or workflow contracts without a
human gate.
