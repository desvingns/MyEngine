# Reference Policy Memory

Short operational form of `docs/DECISIONS/ADR-0000-license-policy.md`.

- Mechanics, rules, tech trees, and data-table structure may be cloned closely from references.
- Do not copy code, assets, schemas, prompt text, generated adapters, exact names, or
  UI strings from reference projects without a dedicated ADR.
- GPL, MPL, unknown-license, custom-license, and local-unspecified sources are study-only until a
  dedicated ADR approves exact reuse.
- Permissive sources still need attribution and an ADR for direct file reuse.
- Dependencies must be approved through a stack/module ADR before being added.
- When unsure, summarize the idea in original words and implement an original solution.
