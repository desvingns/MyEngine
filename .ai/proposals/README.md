# Proposals

This directory stores proposed changes that require human approval before being applied.

Use it for:

- agent/skill/pipeline improvements;
- architecture changes that need ADR discussion;
- self-improvement suggestions from retros;
- large refactors or scope changes.

Proposal files should include:

- problem;
- evidence;
- proposed change;
- target files;
- expected effect;
- risks;
- required human decision.

Approved proposals should be applied in small patches and logged in `.ai/changes/agent-skill-log.md`
when they affect the agentic pipeline.
