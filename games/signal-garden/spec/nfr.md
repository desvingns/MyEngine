# Non-Functional Requirements

- `NFR-001`: JVM replay tests pass on every engine change.
- `NFR-002`: Content validation must pass before a game build is called done.
- `NFR-003`: Save/load roundtrip must preserve stable hash for the target scenario.
- `NFR-004`: Android debug assemble must pass for every milestone.
- `NFR-005`: Headless scenario should stay under 2 ms per tick on the desktop harness.
