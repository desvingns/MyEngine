# User Stories

- `US-001` links `FR-003`: As a player, I can place a tower where the map allows building so that I
  can shape defense.
- `US-002` links `FR-004`, `FR-005`, `FR-006`: As a player, I see storm enemies advance and towers
  respond so that the threat is understandable.
- `US-003` links `FR-007`: As a player, I gain charge from a simple producer so that building has a
  resource tradeoff.
- `US-004` links `FR-008`, `FR-009`: As a developer, I can save, load, and replay the same scenario
  so that regressions are caught.
